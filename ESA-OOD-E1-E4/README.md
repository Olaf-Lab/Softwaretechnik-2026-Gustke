\# ESA-OOD-E1-E4 – Object-Oriented Design und DDD



Im Rahmen dieser Einsendeaufgabe wurden verschiedene Methoden aus dem Bereich Domain-Driven Design (DDD) und Object-Oriented Design (OOD) auf den Smart Task Manager angewendet.



\## Enthaltene Inhalte



\- Event Storming

\- Domain Events

\- Boundaries und Bounded Contexts

\- Core Domain Chart

\- Domain Mappings / Relationships

\- Bounded Context Canvas



\## Ziel der Ausarbeitung



Ziel war die fachliche Analyse und Strukturierung der Anwendung mithilfe moderner DDD- und OOD-Methoden. Dabei wurden fachliche Verantwortlichkeiten, Domänen, Beziehungen und Schnittstellen identifiziert und modelliert.
