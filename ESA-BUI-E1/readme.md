\## Beschreibung



Diese Abgabe entstand im Rahmen der Einsendeaufgabe BUI-E1 (Buildmanagement).



Ziel der Aufgabe war es, praktische Erfahrungen mit zwei Buildmanagement- bzw. CI/CD-Systemen zu sammeln und die Durchführung anhand von Screenshots zu dokumentieren.



Für die Bearbeitung wurden folgende Systeme verwendet:



\* Jenkins

\* GitHub Actions



\## Inhalt



\* BUI-E1-Gustke.pdf

\* Verwendete Screenshots

\* Projektdokumentation



\## Praktische Durchführung



Im Rahmen der Bearbeitung wurde Jenkins lokal installiert und eingerichtet. Zusätzlich wurde GitHub Actions verwendet, um einen Workflow zu erstellen und erfolgreich auszuführen.



Dabei wurden auftretende Probleme, deren Lösungen sowie die gewonnenen Erfahrungen dokumentiert.
