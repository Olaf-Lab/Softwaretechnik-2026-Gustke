# Features

## Bereits umgesetzt

- Modernes GUI auf Basis des in DEV-E1 entwickelten Designs
- Aufgabenübersicht
- Anzeige von Prioritäten
- Statusanzeige für Aufgaben
- Übersichtliche Navigation
- Vorbereitung einer REST-API
- JSON-basierte Datenhaltung

## Geplante Erweiterungen

- Aufgaben erstellen
- Aufgaben bearbeiten
- Aufgaben löschen
- Suchfunktion
- Kategorien verwalten
- Benutzeranmeldung
- Erinnerungsfunktion
- Kalenderintegration

## Ziel

Der Smart Task Manager soll als leicht verständliche Beispielanwendung dienen und gleichzeitig die Grundlage für die verteilte Anwendung in DEV-E3 bilden.
