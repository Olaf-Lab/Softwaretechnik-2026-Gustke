# MET-E1 – Metriken

## Übersicht

Diese Einsendeaufgabe behandelt die praktische Anwendung von Werkzeugen zur statischen Codeanalyse und Softwaremetrik.

## Kurzüberblick

Im Rahmen der Aufgabe wurden die Werkzeuge **Checkstyle** und **PMD** in ein bestehendes Maven-Projekt integriert, ausgeführt und hinsichtlich ihrer Ergebnisse ausgewertet.

## Inhalt

* Integration der Werkzeuge in Maven
* Durchführung der statischen Codeanalyse
* Interpretation der Analyseergebnisse
* Vergleich der Werkzeuge Checkstyle und PMD
* Dokumentation der Ergebnisse

## Wichtige Dateien

* `MET-E1-Gustke.pdf` – Abgabedokument
* `pom.xml` – Maven-Konfiguration
* `src/` – analysierter Java-Quellcode
* `Screenshots/` – Nachweise der Werkzeugausführung

## Verwendete Werkzeuge

* Checkstyle
* PMD
* Maven
* Visual Studio Code
