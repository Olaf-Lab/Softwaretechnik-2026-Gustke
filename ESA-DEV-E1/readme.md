\# ESA-DEV-E1 – GUI-Prototyping mit Google Stitch



\## 1. Aufgabenstellung



Ziel der Aufgabe war es, mit einem AI-/GenAI-Werkzeug eine Benutzeroberfläche für eine eigene Projektidee zu entwerfen. Verwendet wurde Google Stitch. Die Prompts und entstandenen Screens werden in diesem Repository dokumentiert.



\## 2. Projektidee



Als Projektidee wurde ein Smart Task Manager gewählt. Die Anwendung soll persönliche Aufgaben, Prioritäten, Termine und Bearbeitungsstände übersichtlich darstellen.



\## 3. Verwendetes Werkzeug



\- Google Stitch

\- AI-/GenAI-Unterstützung zur UI-Erstellung

\- Git

\- GitHub zur Dokumentation

\- Markdown (README-Dokumentation)



\## 4. Entworfene Screens



\- Dashboard / Startseite

\- Kalenderansicht

\- Aufgabenübersicht

\- Aufgaben-Detailansicht

\- Aufgabe erstellen oder bearbeiten



\## 5. Prompt 1 – Erster Entwurf



\### Ziel



Entwicklung einer modernen Benutzeroberfläche für einen Smart Task Manager zur Verwaltung persönlicher Aufgaben, Prioritäten und Termine.



\### Prompt



Create a modern and minimalistic web application UI for a Smart Task Manager. The application should include a dashboard with a sidebar navigation, task overview cards, a task detail panel, priority labels, due dates, progress indicators and a clean responsive layout. Use a modern student-friendly productivity design with soft colors, rounded corners and clear typography. Include views for task creation, task editing, status management and category filtering. The interface should look like a realistic productivity SaaS application.



\### Ergebnis



Google Stitch erzeugte einen ersten Entwurf eines modernen Dashboards mit Sidebar, Aufgabenkarten und einer übersichtlichen Benutzeroberfläche.



\### Screenshot 1 – Erster Entwurf



!\[Erster Entwurf](screenshots/01\_dashboard\_initial.png)



Der erste Prompt erzeugte einen modernen Smart Task Manager mit Dashboard, Seitenleiste und Aufgabenübersicht. Bereits der erste Entwurf erfüllte die grundlegenden Anforderungen hinsichtlich Übersichtlichkeit und moderner Gestaltung.





\## 6. Prompt 2 – Erweiterung der Benutzeroberfläche



\### Ziel



Im zweiten Schritt sollte die Anwendung um eine Kalenderansicht erweitert werden, damit Termine und Aufgaben gemeinsam dargestellt werden können.



\### Verwendeter Prompt



Please integrate a calendar into the Smart Task Manager dashboard. Display monthly, weekly and daily planning views together with the existing task overview.



\### Screenshot 2 – Kalenderintegration



!\[Kalender](screenshots/02\_calendar\_added.png)



Google Stitch ergänzte die Anwendung um eine Kalenderansicht. Durch weitere Prompts konnte das Layout schrittweise verbessert und an die gewünschte Benutzeroberfläche angepasst werden.





\## 7. Prompt 3 – Finaler Entwurf



\### Ziel



Im letzten Schritt wurde das Layout weiter optimiert. Ziel war eine vollständige Benutzeroberfläche mit Dashboard, Detailansicht und einer konsistenten Designsprache.



\### Screenshot 3 – Finales Design



!\[Finales Design](screenshots/03\_final\_design.png)



Der finale Entwurf zeigt eine moderne Benutzeroberfläche mit Dashboard, Aufgabenverwaltung und Detailansicht. Durch die iterative Zusammenarbeit mit Google Stitch entstand schrittweise ein deutlich ausgereifteres Ergebnis als beim ersten Entwurf.





\## 8. Reflexion



Google Stitch ermöglichte eine schnelle Erstellung erster Benutzeroberflächen und unterstützte insbesondere die iterative Verbesserung des Designs. Durch gezielte Prompts konnten einzelne Funktionen und Layouts schrittweise erweitert und angepasst werden.



Die Arbeit zeigte jedoch auch, dass die Ergebnisse der KI fachlich überprüft und teilweise nachbearbeitet werden müssen. Erst durch mehrere Prompt-Iterationen entstand eine konsistente und benutzerfreundliche Oberfläche.



\## 9. Fazit



Im Rahmen dieser Aufgabe wurde mit Google Stitch eine moderne Benutzeroberfläche für einen Smart Task Manager entwickelt. Die Anwendung entstand schrittweise durch mehrere Prompts und deren iterative Verbesserung. Das Ergebnis demonstriert, wie GenAI den Entwurfsprozess von Benutzeroberflächen beschleunigen kann, während die fachliche Bewertung und Steuerung weiterhin durch den Entwickler erfolgt.
