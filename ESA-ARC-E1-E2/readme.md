\# ARC-E1 / ARC-E2 – Softwarearchitektur



\## Übersicht



Diese Einsendeaufgabe behandelt den Entwurf einer Softwarearchitektur sowie die Dokumentation eines Architekturbausteins mithilfe eines Architecture Communication Canvas.



\## Kurzüberblick



Im Rahmen der Aufgabe wurde für die \*\*Software Quality Platform\*\* eine mehrschichtige Softwarearchitektur entwickelt und anhand eines Komponentendiagramms visualisiert. Ergänzend wurde ein Architecture Communication Canvas zur Beschreibung der Architektur erstellt.



\## Inhalt



\* Architekturentwurf der Software Quality Platform

\* Komponentendiagramm

\* Architekturprinzipien und Architekturstil

\* Frameworks und Qualitätsmerkmale

\* Architecture Communication Canvas (ARC-E2)
