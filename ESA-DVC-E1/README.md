\# ESA-DVC-E1 – Versionsverwaltung mit Git



In dieser Einsendeaufgabe wurde der praktische Umgang mit Git und GitHub umgesetzt. Ziel war es, zentrale Funktionen der Versionsverwaltung anhand eines eigenen Projekts nachzuweisen.



\## Umgesetzte Inhalte



\- Git-Repository erstellt

\- Dateien versioniert

\- Änderungen mit add, commit und push übertragen

\- git status und git diff genutzt

\- Branches erstellt

\- Merge durchgeführt

\- Merge-Konflikt gelöst

\- Zeitreise über Commit-Historie durchgeführt

\- externer Pull Request erstellt
